# CryptoBuddy: Your Eco-Friendly Crypto Advisor

## Overview
A simple rule-based Python chatbot that analyzes cryptocurrency data for profitability (price trends, market cap) and sustainability (energy use, scores). Built with if-else logic and a predefined dataset.

## How It Works
- **Data:** Dictionary-based crypto DB (Bitcoin, Ethereum, Cardano, Solana).
- **Logic:** Keyword matching for queries like "trending" or "sustainable".
- **Rules:** Prioritizes rising trends for profit; low energy for eco-friendliness.
- **Test:** Run in Jupyter/Colab—see screenshots!

## Files
- `CryptoBuddy_Chatbot.ipynb`: Main notebook with code and tests.
- `chatbot-conversation.png`: Sample interaction.

## 50-Word Summary: How This Mimics Basic AI Decision-Making
CryptoBuddy mimics AI by using if-else rules to parse keywords, query a data dictionary, and apply logic like max() for scores or filters for trends. This simulates pattern-matching and rule-based inference, deciding recommendations on profitability/sustainability without machine learning—simple, transparent, and beginner-friendly.
